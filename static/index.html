💡 Mac'te 2 Dakikada Yerel Modeli Başlatma Rehberi

Eğer Mac'inde henüz Ollama kurulu değilse, Terminal'i açıp şu tek komutu çalıştırman yeterlidir:

brew install ollama && ollama run qwen2.5:7b

Bu komut modeli indirir ve Mac'inin GPU'suyla sessizce hazır tutar. Model indikten sonra Ayna otomatik olarak ona bağlanacaktır.
